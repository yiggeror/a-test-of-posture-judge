## 2. 最重要的发现：耳部遮挡导致的假读数（已用图像证实）

`3820333`：长发完全盖住耳朵，MediaPipe 把 **ear 关键点放在头发上**，
位置明显高于且后于真实耳屏，而 **`visibility` 报 1.000**。
应用据此输出「头前引角 **+25.39°，明显倾向**」。

这在阶段 2 只是理论担忧，现在是**有图像证据的实际失效**。
`visibility` 估计的是"该点是否被遮挡"，不是"该点是否落在正确的解剖位置"，
对这类失效完全没有警示作用。

## 3. 本轮的两项实质改进

### 3.1 视角判定改用躯干偏航角（world landmarks）

旧的「肩宽/躯干长」比值判据在真实数据上被证伪：

| 图 | 旧比值 | 旧判定 | 实测偏航 | 新判定 |
|----|--------|--------|----------|--------|
| 真实正面（n=5） | 0.591–0.659 | front | **5–24°** | front |
| `16135927` | 0.453 | front ❌ | **53.2°** | oblique |
| `16430958` | 0.401 | front ❌ | **58.4°** | oblique |
| 真实侧面（n=4） | 0.039–0.124 | side | **85–88°** | side |

比值把两张旋转了大半个身位的照片判为正面，并在其上算出了高低肩读数；
偏航角以极大的余量把它们分了出来。两侧余量都很宽（24 → 30 → 53，58 → 70 → 85）。

同时**斜侧视角现在一律不出数**。此前 oblique 会把矢状面和正面指标全算一遍——
`16135927` 就曾输出「头前引角 +32.10°，明显倾向」，
那是一张只是转了身的普通照片，属于与手掌照同类的假阳性。

注意：偏航角来自 MediaPipe 的 world-landmark z，是单图模型最不可靠的输出，
且样本只有 n=12。它只用作**粗门**（拒掉中间地带），不作为测量值。

### 3.2 读数附带不确定度

耳部关键点平移 10px（1400px 高的图上）→ 头前引角摆动 **±4.4°**；
而「轻度」与「明显」两档的间距只有 10°。

因此耳依赖的两项指标现在都带 `±`，取耳点抖动 3% 躯干长所产生的摆动幅度
（实测 ±3.2° 至 ±5.8°）。**这个误差与阈值分档同量级**，
意味着当前关键点精度下三档分级并不真正可分辨——界面上已如实写明。

另外实测到：前后方向的敏感度约为垂直方向的 **5 倍**，
因为该角度本质是 atan(水平位移 / 很长的垂直臂)。

## 4. 合理性检查：负样本泄漏率 31/63 → 18/63

62 张负样本（+1 张耳部遮挡案例）逐张实跑。改进前 **31/63（49%）** 仍输出读数。

新增四道闸：

| 闸 | 依据 | 效果 |
|----|------|------|
| 膝关节伸展 ≥150° | 实测站立 175.7–179.4°（n=11），坐姿 35.2/81.2，跪姿 19.0——两群相隔约 90° | 坐/跪/蹲全部拦下 |
| 躯干倾角上限 40°→**25°** | 实测真实站立从未超过 10.2° | 部分弯腰被拦下 |
| 多人检测（`num_poses` 1→2） | 原先模型静默挑一个人来测 | 10 张多人照拦下 7 张 |
| 关键点出框检查 | 模型会把踝点外推到画面外几百像素并给出合理 visibility | 踝依赖指标按需拦下 |

另加两处：耳-踝跨度 > 画面高度（几何上不可能）直接拒；
肩-髋-踝偏差 > 60°（站立人体不可能）直接拒。

**正样本回归：全部 12 张读数与改动前逐位一致**，确认 `num_poses=2` 未扰动主姿态。

### 仍然泄漏的 18 张，以及为什么

- **雕塑 4 + 人体模特 3 + 玩偶 3 = 10 张。** 直立的人像雕塑与站立的人在几何上
  **不可区分**——躯干竖直、膝关节伸展、比例正常。纯几何检查解决不了这一类，
  需要真正的人体/活体分类器。这是本工具当前的硬限制，不打算用更多启发式去凑。
- **手/脚/局部特写 3 张。** 与手掌照同类的置信幻觉。
  `neg_foot_closeup_27542903`（穿袜的小腿特写）被贴上整副人体骨架，
  躯干竖直、膝关节伸展、踝点在框内——**通过了全部几何检查**，
  输出「头前引角 +32.84°，明显倾向」。已确认第二例。
- **弯腰 2 张**：弯腰时膝关节是直的，膝闸抓不到；躯干倾角也未超 25°。
- **多人 2 张**：第二个人过小/过于残缺，`num_poses=2` 没检出。
- **耳部遮挡 1 张**：即 §2 的案例，几何上完全正常。

## 5. 现在能信什么

| 项目 | 状态 |
|------|------|
| 视角判定 | **首次在真实数据上验证**（n=12，两类之间余量很宽） |
| 关键点提取（真实照片、构图合规） | 可信 |
| 几何运算 | 可信，37 项单元测试解析验证 |
| 方向性（符号是否正确） | **首次得到证据**：头后仰 → −5.00°，整体前倾 → 铅垂偏移 +0.77，弯腰 → 大幅负值。符号方向全部正确 |
| 指标互补性 | `32192287` 揭示：整体刚性前倾时肩-髋-踝仍近似共线（−3.41°「正常」），只有铅垂线偏移抓得到（+0.77）。**两项指标不可互相替代** |
| 高低肩 | n=4，真实正面，读数 +0.38 至 +3.88°，量级合理 |
| 头前引角 / 圆肩 | **n=2**，远不足以校准阈值 |
| 全部阈值 | **仍未校准**，与第一轮相同 |
| 假阳性防护 | 从 49% 泄漏降到 29%，但对人像雕塑与局部特写无效 |

**结论没变：阈值依然是拍脑袋的。** 侧面样本从 0 涨到 2，
够验证"符号对不对、代码跑不跑得通"，**不够定"多少度算异常"**。
